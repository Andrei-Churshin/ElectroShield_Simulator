# ⚡ Электрощит — Интерактивный симулятор сборки

Учебный симулятор для изучения схем электрощитов, монтажа компонентов на DIN-рейке и принципов работы защитной аппаратуры.

## 🚀 Запуск

Просто открой `index.html` в любом современном браузере — **сервер не нужен**, интернет не требуется.

```bash
# Или через локальный сервер (для корректной работы ES-модулей в будущем)
npx serve .
# или
python -m http.server 8080
```

## 🎮 Возможности (v0.3+)

- **Два учебных сценария**: бытовой щит и промышленная цепь управления
- **Интерактивная симуляция цепи** (Этап 1):
  - Переключение автоматов, УЗО, контакторов (ВКЛ/ВЫКЛ/СБРОС)
  - Расчёт потенциалов узлов и токов нагрузок (Circuit Solver)
  - Визуализация напряжения: пульсирующие провода, светящиеся клеммы
  - Работа нагрузок: лампа ☀, двигатель ⟳
  - Срабатывание защиты: перегрузка, КЗ, ток утечки (УЗО), тепловое реле
- **Три режима**: Обучение (с подсказками), Практика, Экзамен (без подсказок)
- **Проверка схемы** с подробным отчётом ошибок
- **Адаптивный интерфейс** — работает на планшетах и мобильных
